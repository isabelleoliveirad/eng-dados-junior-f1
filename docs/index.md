# Dashboard F1 — Engenharia de Dados Júnior

Projeto Python didático com ingestão via API OpenF1, modelagem em Pydantic, processamento de voltas, interface Streamlit, testes e integração contínua.

## Executar

```bash
python -m pip install -r requirements-dev.txt
python -m pytest
streamlit run app.py
```

Leia também a [documentação da API](doc_api.md) e a [arquitetura](architecture.md).
